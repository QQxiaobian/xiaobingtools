## 目录约定

每个工具一个独立目录，目录内自带 README，说明用法与运行方式：

```
xiaobingtools/
├── <tool-name>/      # 单个工具，自包含，可独立运行
│   ├── README.md     # 这个工具干什么、怎么跑
│   └── ...
└── README.md         # 本文件，维护工具清单
```

## 提交约定

提交信息用 `<type>: <说明>` 的格式，常见 type：

- `feat` 新功能 / 新增工具
- `fix` 修 bug
- `docs` 只改文档
- `refactor` 重构，行为不变
- `chore` 构建、依赖、配置类杂项
